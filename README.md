# Bitcoin Market Sentiment vs Trader Performance Analysis

## Objective
Analyze the relationship between Bitcoin market sentiment and trader profitability.

## Datasets
1. Bitcoin Fear & Greed Index
2. Hyperliquid Historical Trader Data

## Methodology
- Data Cleaning
- Date Conversion
- Dataset Merging
- Exploratory Data Analysis
- Profitability Analysis
- Sentiment-Based Insights

## Key Findings
- Fear generated the highest total profit ($3.36M)
- Extreme Greed produced the highest average profit per trade ($67.89)
- Fear had the highest trading activity (61,837 trades)
- Extreme Fear showed the lowest market participation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
